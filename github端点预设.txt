# ===== git / GitHub 需要测的端点 =====
# 用法：把本文件内容整段贴到 %APPDATA%\QuickerPing\hosts.txt 里（或复制需要的行），
#       然后在动作窗口点「重新检测」。
# 说明：默认测 443 的 HTTPS（能不能真正打开）；SSH 端口用 tcp/ 前缀，只测端口通不通。

proxy=auto
icmp=off

# ---- git 走 HTTPS（clone / fetch / pull / push）必需 ----
github.com                    网页 + git 传输（HTTPS 443）
api.github.com                API / 令牌校验 / 设备码登录（GCM、gh 命令）
codeload.github.com           下载 zip / tar.gz 源码包
raw.githubusercontent.com     raw 文件
objects.githubusercontent.com Release 附件 / LFS 对象
github.githubassets.com       网页静态资源（浏览器打开 github.com 用）

# ---- git 走 SSH 时（和 HTTPS 二选一即可）----
tcp/github.com:22             SSH 直连（22 端口）
tcp/ssh.github.com:443        22 被封时走 SSH over 443

# ---- 可选：缺了不影响 clone/push，只是网页或 LFS 体验差一点 ----
# alive.github.com              保持登录心跳
# collector.github.com          前端埋点
# media.githubusercontent.com   LFS 下载
# github-cloud.s3.amazonaws.com LFS / 附件走 S3
# avatars.githubusercontent.com 头像
# github.com:80                 纯 HTTP（会 301 跳 HTTPS，一般不用测）
